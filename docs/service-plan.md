# 서비스 기획서

## 서비스 개요

- 서비스명: 오늘도 웃는 몸 — AI 5분 루틴
- 목적: 복잡한 운동 앱에 부담을 느끼는 50대 여성이 현재 몸 상태에 맞는 짧은 저강도 운동을 바로 시작하도록 지원
- 타겟: 혼자 운동을 지속하기 어렵고 무릎·허리 등 관절 부담을 걱정하는 50대 여성
- 사용자 가치: 검색 없이 세 가지 상태 입력만으로 이해하기 쉬운 개인화 루틴 확인

## 페이지·섹션 구성

1. 홈: 서비스 가치와 핵심 행동 제시
2. AI 코치: 컨디션·불편 부위·시간 입력 및 결과 출력
3. 이용 안내: 3단계 사용법
4. 안전 원칙: 운동 중단 기준과 환경 안내

상단 메뉴와 각 CTA가 앵커 이동을 제공하며 모바일에서는 접이식 메뉴를 사용합니다.

## AI 기능 기준

| 구분 | 기준 |
| --- | --- |
| 입력 | 컨디션, 불편 부위, 가능 시간, 선택 메모 |
| 출력 | 루틴 제목, 요약, 3~5개 동작, 각 시간·설명, 안전 안내 |
| 가치 | 사용자가 지금 가능한 짧은 동작을 결정하도록 도움 |
| 빈 입력 | 누락 항목 안내 후 해당 필드로 포커스 이동 |
| API 오류 | 이해하기 쉬운 오류 문구와 다시 시도 버튼 제공 |
| 지연 | 20초 후 요청 중단 및 재시도 안내 |
| 안전 | 의료 진단 배제, 통증·어지럼증·호흡곤란 시 중단 안내 |

무료 Gemini API 사용 시 이름, 연락처, 상세 의료기록 등 개인정보를 입력하지 않도록
안내하며, 무료 사용 한도를 초과하면 재시도 메시지를 표시합니다.

## 데이터 흐름

`사용자 입력 → JavaScript 검증 → fetch('/api/routine') → Python 함수 → OpenAI API → JSON 결과 → DOM 렌더링`
